# Heatline

משחק בלוקים בשבעה שלבים עם פתיל בוער. Progressive Web App: מתקינים מהלינק, עובד אופליין.

- `index.html` — המשחק כולו, קובץ אחד
- `manifest.webmanifest` — הגדרות ההתקנה (שם, אייקון, מסך מלא)
- `sw.js` — Service Worker: המשחק עובד גם בלי אינטרנט

התקנה בטלפון: פתחו את הלינק, ואז "הוסף למסך הבית".
