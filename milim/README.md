# אוצר — אימון אוצר מילים לפסיכומטרי

אפליקציית ווב (PWA) ללימוד אוצר המילים של החלק המילולי בפסיכומטרי.
עובדת בדפדפן, מותקנת למסך הבית, וכל הנתונים נשמרים במכשיר — בלי שרת ובלי חשבון.

## מה יש בפנים

**מאגר** — 300 מילים מנוקדות עם חלק דיבר, הגדרה, משפט לדוגמה, נרדפות וניגודים,
מחולקות לחמש קטגוריות (פעלים, שמות תואר, שמות עצם, מילים לועזיות, ביטויים)
ולשלוש רמות קושי.

**מסך הבית (לוח מחוונים)** — טבעת היעד היומי, מה כדאי לעשות עכשיו (חזרה, מילים
חדשות, תיקון טעויות, תרגול ממוקד בקטגוריה החלשה), מילת היום, מבט מהיר על הנתונים
וכל האפשרויות במקום אחד. ניווט תחתון קבוע בין חמשת המסכים.

**חיפוש ושדרוג שפה** — שתי לשוניות. *מילון*: חיפוש בכל המאגר לפי מילה, פירוש,
מילה נרדפת או משפט לדוגמה. *שדרוג שפה*: כותבים מילה יומיומית ("חזק", "בעיה",
"להגיד") ומקבלים את החלופות בשפה גבוהה עם פירוש קצר — 140 מילות מפתח ו־425
חלופות, בתוספת חיפוש הפוך אוטומטי במאגר עצמו.

**שכתוב משפטים** — כותבים משפט בשפה יומיומית ומקבלים אותו בעברית תקנית ומנוקדת.
כל מילה שהוחלפה ניתנת להקשה: פירוש, חלופות אחרות, או חזרה למקור. המנוע מבוסס
לקסיקון ולא ניחוש — שני צדי ההחלפה נכתבים באותה נטייה דקדוקית, ולכן התוצאה
תקינה. מטופלות גם תחיליות ו׳ ו־ה׳ הידיעה (כולל שורוק ודגש).

**מסך הכרטיס** — מילה אחת גדולה, החלקה למילה הבאה, הקראה בעברית (Web Speech),
סימון "ידעתי", הוספה לאוסף, שיתוף, וגיליון מידע עם משפט לדוגמה ונרדפות.

**חזרה מרווחת** — כל מילה מתקדמת בין שבע תיבות בשיטת לייטנר
(0, 1, 2, 4, 8, 16, 32, 64 ימים). "לחזרה היום" מציג רק את מה שהגיע זמנו.

**תרגולים**
| מצב | מה זה |
|---|---|
| כרטיסיות | דירוג עצמי: לא ידעתי / כמעט / ידעתי |
| אמריקאי | מילה↔הגדרה + מילים נרדפות, ארבע אפשרויות |
| השלמת משפטים | המילה מוסתרת בתוך משפט אמיתי |
| תשבץ | תשבץ שנבנה אוטומטית מהגדרות המאגר |
| ספרינט | 60 שניות, כמה שיותר תשובות |
| שלמות | 15 שאלות, טעות אחת מסיימת |
| אלימינציה | פסילת שלוש ההגדרות השגויות |
| התאמה | חיבור מילים לפירושים בשלושה סבבים |
| גרדום | ניחוש אותיות המילה לפי ההגדרה, שישה חיים |
| הפכים | איזו מילה הפוכה במשמעות |
| הטעויות שלי | רק המילים שנפלתי בהן |
| האוסף שלי | המילים שסימנתי |

**התקדמות** — שליטה כוללת, יעד יומי, דיוק, רצף ימים, מפת פעילות של 68 ימים,
שליטה לפי קטגוריה, המילים הקשות ביותר וספירה לאחור לתאריך המבחן.

**עיצוב** — ארבע ערכות צבע (דיו, נייר, לילה, מרווה) ומצב מבחן שמסתיר את הפירוש.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מעטפת: גופנים, מניפסט, טעינת הסקריפטים |
| `data.js` | מאגר המילים (`window.WORDS`) והקטגוריות |
| `rewrite.js` | לקסיקון השכתוב: צירופים (`window.PHRASES`) וצורות נטויות (`window.FORMS`) |
| `thesaurus.js` | מילון השדרוג (`window.UPGRADES`): מילה פשוטה ← חלופות גבוהות |
| `app.js` | כל הלוגיקה: מצב, חזרה מרווחת, מסכים, מנוע השאלות, התשבץ |
| `styles.css` | עיצוב וערכות הצבע (משתני CSS) |
| `sw.js` | Service Worker — עבודה אופליין |
| `manifest.webmanifest` | הגדרות ההתקנה |

## הרצה

```bash
cd milim && python3 -m http.server 8000
```
ואז לפתוח `http://localhost:8000`. בטלפון: "הוסף למסך הבית".

## הוספת מילים

מוסיפים ערך ל־`data.js`:

```js
{w:"מִלָּה מְנֻקֶּדֶת", p:"שם עצם", d:"הגדרה קצרה",
 e:"משפט לדוגמה שבו המילה מופיעה.", s:["נרדפת"], a:["ניגוד"], c:"noun", l:2}
```

להוספת שדרוג שפה, ב־`thesaurus.js`:

```js
{k:"חזק", u:[["אֵיתָן","יציב, שאינו נשבר"],["תַּקִּיף","נחוש ואינו מתפשר"]]}
```

`k` נכתב בלי ניקוד — זה מה שהמשתמש מקליד. חלופה שקיימת גם במאגר הופכת לקישור לכרטיס.

`c` — אחת מ־`verb`/`adj`/`noun`/`foreign`/`idiom`. `l` — 1 עד 3.
המזהה של המילה נגזר מהכתיב בלי ניקוד, ולכן שינוי ניקוד שומר על ההתקדמות.
משפט הדוגמה הוא שמזין את תרגול השלמת המשפטים — כדאי שהמילה תופיע בו.

## הערה על התוכן

ההגדרות, הניקוד ומשפטי הדוגמה נכתבו עבור הפרויקט הזה ולא עברו הגהה לשונית.
לפני שימוש מסחרי כדאי שעורך לשון יעבור על המאגר.
